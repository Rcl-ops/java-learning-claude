# 04 · 运算符与表达式

**学习目标**：熟练使用算术、关系、逻辑、位运算与三元运算符，了解优先级与常见陷阱。

## 1. 算术运算符

| 运算符 | 含义 | 例 |
|--------|------|----|
| `+ - * / %` | 加减乘除取余 | `7 / 2 = 3`、`7 % 2 = 1` |
| `++` `--` | 自增自减 | `i++` 先用后加，`++i` 先加后用 |

```java
int a = 7;
System.out.println(a / 2);       // 3   整数除法舍弃小数
System.out.println(a / 2.0);     // 3.5
System.out.println(-7 / 2);      // -3  向 0 取整
System.out.println(-7 % 3);      // -1  结果符号与被除数相同
System.out.println(Math.floorMod(-7, 3)); // 2  数学意义的取模
// System.out.println(1 / 0);    // ArithmeticException: / by zero
System.out.println(1 / 0.0);     // Infinity  浮点除零不抛异常
System.out.println(0.0 / 0.0);   // NaN
```

```java
int i = 5;
int j = i++ + ++i;   // i++ 取 5 然后 i=6；++i 变 7 取 7；j = 12
```

> 别写这种代码。**一行里不要对同一变量多次自增**。

## 2. 赋值与复合赋值

```java
int x = 10;
x += 5;   // x = x + 5
x -= 3; x *= 2; x /= 4; x %= 3;
byte b = 10;
b += 5;   // ✅ 复合赋值隐含强制转换，等价于 b = (byte)(b + 5)
// b = b + 5;  // ❌ 编译错误
```

## 4. 逻辑运算符与短路

| 运算符 | 含义 | 特点 |
|--------|------|------|
| `&&` | 与 | **短路**：左边为 false 则不再计算右边 |
| `\|\|` | 或 | **短路**：左边为 true 则不再计算右边 |
| `!` | 非 | |
| `&` `\|` `^` | 非短路与/或/异或 | 两边都会计算 |

```java
String s = null;
if (s != null && s.length() > 0) { ... }   // 安全：s 为 null 时不会执行 s.length()
if (s.length() > 0 && s != null) { ... }   // ❌ 先 s.length() → NPE
```

## 5. 位运算（理解即可，模组/底层/性能场景常见）

| 运算符 | 含义 | 例 |
|--------|------|----|
| `&` | 按位与 | `0b1100 & 0b1010 = 0b1000` |
| `\|` | 按位或 | `0b1100 \| 0b1010 = 0b1110` |
| `^` | 按位异或 | `0b1100 ^ 0b1010 = 0b0110` |
| `~` | 按位取反 | `~0 = -1` |
| `<<` | 左移 | `1 << 3 = 8`（相当于 ×2³） |
| `>>` | 带符号右移 | `-8 >> 1 = -4` |
| `>>>` | 无符号右移 | `-1 >>> 28 = 15` |

用整数的每一位表示一个开关（**标志位**）：

```java
final int READ = 1;       // 0b001
final int WRITE = 1 << 1; // 0b010
final int EXEC = 1 << 2;  // 0b100
int perm = READ | WRITE;                 // 授予读写
boolean canWrite = (perm & WRITE) != 0;  // 检查
perm &= ~WRITE;                          // 撤销写
perm ^= EXEC;                            // 翻转执行位
```

## 6. 三元运算符

```java
int score = 72;
String result = score >= 60 ? "及格" : "不及格";
String level = score >= 90 ? "优" : score >= 80 ? "良" : score >= 60 ? "中" : "差"; // 嵌套，不宜过长
```

## 7. 字符串拼接 `+`

```java
System.out.println("1 + 1 = " + 1 + 1);     // 1 + 1 = 11
System.out.println("1 + 1 = " + (1 + 1));   // 1 + 1 = 2
System.out.println(1 + 1 + " 是结果");        // 2 是结果
```

从左向右计算，一旦遇到字符串，后面全部变成字符串拼接。

## 8. instanceof（先预览）

```java
Object o = "hello";
if (o instanceof String s) {               // Java 16+ 模式匹配：判断并同时声明变量
    System.out.println(s.toUpperCase());
}
```

## 9. 优先级（记大概，不确定就加括号）

`() [] .` > `! ~ ++ --` > `* / %` > `+ -` > `<< >> >>>` > `< <= > >= instanceof` > `== !=` > `&` > `^` > `|` > `&&` > `||` > `?:` > `= += ...`

## 小结

- 整数除法舍弃小数；`%` 符号跟被除数；整数除零抛异常，浮点除零得无穷。
- `&&` `||` 短路，常用来先判空再调用。
- 复合赋值自带强转；字符串拼接从左到右。
- 位运算用于标志位与底层处理。
