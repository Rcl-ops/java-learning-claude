# 00 · 学习路线与使用说明

> 本教程面向**零基础或刚入门**的 Java 学习者。目标：学完后能独立写出几百行规模的命令行/小型服务程序，并能读懂、改写一个 Minecraft（NeoForge）模组。

## 1. 本项目由三部分组成

| 部分 | 位置 | 用法 |
|------|------|------|
| ① 核心语法教学 | `docs/` | 按编号顺序阅读，边读边敲代码 |
| ② 练习题 | `exercises/` | 题目与答案**分开存放**；先做题，再对照答案 |
| ③ 应用案例与项目 | `projects/` | 5 个可运行的小项目 + 1 个 Maven 示例，其中包含最简 NeoForge 模组 |

## 2. 推荐学习节奏（8 周，每周 8~10 小时）

| 周次 | 阅读章节 | 对应练习 | 本周产出 |
|------|----------|----------|----------|
| 1 | 01 环境、02 入门、03 变量与类型、04 运算符 | `basics` | 能写出打印、计算类小程序 |
| 2 | 05 流程控制、06 数组、07 方法 | `flow`、`arrays` | 九九乘法表、冒泡排序、斐波那契 |
| 3 | 08 字符串、09 类与对象 | `strings`、`oop`(1~3) | 一个带封装的 `BankAccount` |
| 4 | 10 继承多态、11 抽象/接口/枚举/record、12 泛型 | `oop`(4~9) | 图形面积多态程序 |
| 5 | 13 异常、14 集合 | `exceptions`、`collections` | 词频统计、LRU 缓存 |
| 6 | 15 Lambda 与 Stream、16 IO、17 常用 API | `functional` | 用 Stream 重写前面的循环 |
| 7 | 18 并发、19 注解与反射、20 现代 Java | `concurrency` | 线程池求和、生产者消费者 |

> 时间只是参考。**卡住不要硬撑超过 30 分钟**：缩小问题 → 打印中间值 → 查文档 → 再问人/问 AI。

## 3. 高效学习的 5 条原则

1. **每个示例都亲手敲一遍**，不要复制粘贴。敲错、报错、改错，本身就是学习。
2. **先预测再运行**：运行前先想"它会输出什么"，不一致时就是你学到东西的时刻。
3. **学会读报错**：Java 的报错信息非常具体（见第 23 章）。第一行 + 第一个带你代码行号的栈帧，通常就是答案。
4. **小步迭代**：每写 5~10 行就运行一次，不要写 200 行再调试。
5. **做题 > 看书**：看懂 ≠ 会写。每章至少完成对应练习的前 3 题。

## 4. 版本约定

- 教程默认使用 **Java 21（LTS）** 语法，示例均可在 Java 21 及以上编译运行。
- 第 20 章会介绍 Java 22~25 的新特性；**NeoForge 26.1 模组项目需要 JDK 25**（见 `projects/05-neoforge-hello-mod`）。
- 建议你直接安装 **JDK 25（LTS）**：它向下兼容本教程全部示例，同时满足模组开发。
